# Story

As a track plan author, I want to pan and zoom the canvas, so that I can see as much or as little of the layout as I like.

# Elaboration

The layout exists on an infinite canvas.

# Constraints

1. There are minimum and maximum practical zoom levels.

# UX

Pinch gestures (trackpad) and scroll wheel (mouse) zoom in and out.

Holding shift or the scroll wheel while dragging the mouse pointer pans.

The zoom-to-fit button centers the layout in the viewport.

# UI

There is a zoom-to-fit button.
